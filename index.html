01 · Featured · Regression

House Price Prediction

A regression model that predicts the sale price of a house from its property features, such as overall quality, living area, basement size, lot size, year built, garage size and neighborhood.

Trained on the Ames, Iowa housing data and scored once on houses the model never saw during training.

Approach

How each project is built

  1. 01

    Explore the data

    Look at distributions, missing values and odd records before deciding what to clean.

  2. 02

    Build a baseline

    Start with a simple model, so every later improvement has something to beat.

  3. 03

    Evaluate honestly

    Use cross-validation, keep a test set aside, and report errors in plain terms.

  4. 04

    Improve the model

    Compare stronger models and tune them, keeping a change only when it clearly helps.

About

About this portfolio

This portfolio is about practical machine learning: real datasets, clear questions and models that are measured carefully rather than presented as magic.

Each project is documented from the first look at the data to the final evaluation, including the limits of what the model can do. The code for each project is on GitHub.
